Cómo usar Errand

Errand te permite cambiar este repositorio enviando un mensaje por Telegram. No necesitas abrir un editor ni una terminal.

Cómo funciona

  1. Escribe un encargo por Telegram describiendo el cambio que quieres en el repositorio.
  2. Errand trabaja solo: lee el código, hace el cambio y ejecuta los tests, el linter o el build si existen.
  3. Recibes un resumen de lo que se ha hecho y se abre una Pull Request con el cambio para que lo revises.

Funcionalidades

  • Encargos en lenguaje natural: cualquier mensaje se interpreta como una petición de cambio.
  • Cambios mínimos: solo toca lo necesario para completar el encargo, sin reformatear ni refactorizar el resto.
  • Respeta las convenciones del repositorio: lee el CLAUDE.md si existe y lo sigue.
  • Comprobaciones automáticas: si el repositorio tiene tests, linter o build, se ejecutan antes de terminar y se arreglan los fallos que haya provocado.
  • Preguntas cuando hace falta: si falta información o hay varias opciones razonables, Errand se detiene y te hace una pregunta, a menudo con opciones cortas para elegir. Tu respuesta le llega en el siguiente turno.
  • Imágenes como contexto: puedes adjuntar imágenes al encargo. Se usan como referencia y no se copian al repositorio salvo que lo pidas.
  • Pull Request automática: Errand se encarga de hacer el commit, el push y abrir la PR. El título y la descripción salen del resumen final.
  • Resumen en castellano: las preguntas y el resumen final siempre se escriben en español.

Consejos para escribir buenos encargos

  • Sé concreto: indica qué archivo o qué comportamiento quieres cambiar.
  • Pide una cosa por encargo para obtener PRs pequeñas y fáciles de revisar.
  • Si algo no sale como esperabas, envía otro encargo describiendo el ajuste.
